# Chacha Bhatija Restaurant

A responsive restaurant ordering website where customers can explore the menu, add dishes to their cart, enter delivery details, and prepare their Cash on Delivery order to send through WhatsApp.

## Live Demo

You can visit the website here: 👉 [Chacha Bhatija Restaurant](https://saurav56295.github.io/chacha-bhatija-restaurant/)

## Features

- Photo menu with dish names and prices
- Add dishes to the cart and adjust quantities
- Cart total updates automatically
- Add-to-cart popup notification
- Customer name, phone number, and delivery address form
- Cash on Delivery checkout
- WhatsApp order message with customer and order details
- Responsive layout for mobile and desktop

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

Keep the food photos inside the `images` folder so the menu images load correctly.

## WhatsApp orders

The seller's WhatsApp number is set in `script.js`. Update `SELLER_WHATSAPP` with the seller's number in international format, using digits only.

When a customer places an order, WhatsApp opens with the order details filled in. The customer reviews the message and taps **Send** to submit it.

Online payment is shown as coming soon and is currently disabled.
